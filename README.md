# ✉️ Inprocica International - Mailer API

A lightweight Express.js backend service to handle contact form submissions for [Inprocica International](https://inprocicainternational.com/). It securely processes requests and sends emails using the Resend API.

## 🛠️ Tech Stack

* **Node.js & Express.js**
* **Resend SDK** (Email service)
* **CORS & Dotenv** (Security & Configuration)
